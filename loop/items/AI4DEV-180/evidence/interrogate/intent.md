This branch is phase 2 of the Discovery screen: it builds the real Discovery screen components in `src/components/discovery/` on fixture data, before any backend wiring. The screen follows revision 12 of `design/discovery-ui-contract.md` (read it in the checkout; it is the contract) and the canvas boards in `design/astra/canvas-rev12/`. The components talk only to a port (`src/components/discovery/port.ts`): a chat transport for AI replies (AI SDK `useChat` with a streaming transport) plus calls for brief edits, file upload, file chat, confirmation and usage. Phase 3 will implement the same port with edge functions; the UI must never touch the database directly. In this branch the port is implemented by a fixture shell under `design/astra/src/` (`fixture-world.ts` holds an in-memory world with revisions and charges, `fixture-transport.ts` streams scripted replies, `fixture-port.ts` assembles them, `fixture-data.ts` and `givens.ts` hold the scripted data). The screen has desktop and phone layouts. Screen acceptance tests AT-004.61 to .73 in `tests/at/suites/req-004/j-need-brief.test.ts` drive the fixture shell in a real browser through `tests/at/harness/screen.ts`, which talks over JSON lines to a Node Playwright host `tests/at/harness/screen-host.mjs` (Playwright hangs under Bun on Windows). AT-004.67 and .68 run only their screen half and stay pending; .69 is not built here. Key contract rules: manual brief edits cost no AI turn and save with "Save change" using a base revision; after the NGO confirms the brief, AI questions and charges stop, and a saved change reopens Discovery; a file chat is an AI reply about one uploaded file and may pause with a question. The old design-only mock files under `design/astra/src/` (Discovery.tsx, DiscoveryProgress.tsx, DiscoveryReferences.tsx, DiscoveryScope.tsx, discovery-chat.css, discovery-examples.ts) are deleted, replaced by the real components; their deleted bodies are left out of the diff below. The canvas board HTML, bun.lock and the item's loop records are also left out. The checkout is your working directory: read any file you need.
