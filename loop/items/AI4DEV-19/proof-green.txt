HOW THESE TRANSCRIPTS WERE CAPTURED. stdout and stderr are redirected to separate files, and the
redirection is done by `cmd` rather than by PowerShell. PowerShell 5.1 wraps a native command's

console width. Routing through `cmd` writes the child's bytes untouched.

WHAT NO PROOF FILE COVERS, and where to find it instead. The two repairs round 2 made are guarded by
conformance cases rather than by a transcript here, which is the whole point of them: a captured
failure proves a repair worked once, and a case that stays in the tree fails the day someone undoes
it. `consumes no event id when the crash rolls the emit back` yields event-2 against the pre-fix
allocation; `lets the process that first sent a delivery keep it` reports the last drain's identity
if the stamp guard is removed. Both live in tests/at/harness/conformance.selftest.ts and run under
`bun run at:selftest`, which is not part of the --expect gate above — the selftests are excluded
from an acceptance run by design, so that gate is not evidence about them.
