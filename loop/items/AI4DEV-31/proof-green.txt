3. THE ATTACK THAT SURVIVED THE FIRST FIX, AND WHAT CLOSING IT ACTUALLY BOUGHT
------------------------------------------------------------------------------

With `bindSuite`, `atTest` and `defineEvidenceCapture` all derived and all converted to consts, this
still compiled CLEAN, measured in isolation:

  async (ctx: AtContext<NotificationsSut & { invented?: string }, World>) => {
    const { sut } = await ctx.open();
    void sut.invented;                       // string | undefined; `undefined` at run time
  }

$ node ... -p (isolated single-attack config)
EXIT=0

Widening happens at the BODY, not at the entry point, so closing the entry points did not reach it.
And nothing structural can: `NotificationsSut` and `NotificationsSut & { invented?: string }` are
assignable in BOTH directions — an optional member adds no obligation — so no variance annotation
and no conditional "exactly this type" trick can distinguish them.

So `OpenWorld`, `AtContext`, `AtTestBody` and `EvidenceCapture` are now exported over `<R, K>` — a
requirement id and a sut key, both of which derive — and the shape-parameterized versions stay
module-private. The attack is line 72 above, and it is rejected.

THIS SECTION USED TO END BY CALLING THE WIDENED TYPE "UNSPELLABLE". THAT WAS FALSE, AND IT IS THE
SAME OVERCLAIM THE ITEM EXISTS TO REMOVE — see section 3b. What the change buys is precisely this:
the API no longer INVITES the widening. It does not prevent it.


3b. WHAT IS STILL OPEN: STRUCTURAL RECONSTRUCTION (Gate 2, confirmed here)
--------------------------------------------------------------------------

Both Gate 2 reviewers independently compiled the refutation, and it was reproduced in this worktree
before being accepted — full transcript with controls in `gate2-widen-reproduction.txt`.

A suite cannot NAME the seam types any more. But `AtContext<R, K>` and `OpenWorld<R, K>` are
exported, because a body has to be able to annotate itself, and a determined author rebuilds the
widened type out of THOSE with `Omit` and an intersection:

  type WidenedOpen = OpenWorld<'req-016', 'notifications'> & {
    sut: { inventedSut?: string };
    w: { inventedWorld?: string };
  };
  type WidenedCtx = Omit<AtContext<'req-016', 'notifications'>, 'open'> & {
    open(): Promise<WidenedOpen>;
  };

  suite.atTest('AT-016.97', 'reads an invented member', async (ctx: WidenedCtx) => {
    const { sut, w } = await ctx.open();
    const readSut: string | undefined = sut.inventedSut;      // compiles; undefined at run time
    const readWorld: string | undefined = w.inventedWorld;    // compiles; undefined at run time
  });

Controls, both passing: `--listFiles` shows the probe file in the compiled program (so exit 0 is not

IT CANNOT BE CLOSED WITH TYPES, for the reason already given in section 3: the derived type and the
derived type intersected with an optional member are assignable both ways. Rejecting this needs a
SOURCE-INSPECTION pass — permit only inline, unannotated suite and capture callbacks, refuse an
explicitly annotated or indirect one — which is a different kind of machinery and is filed as its own
item rather than built here.

THE CLAIM THIS ITEM ACTUALLY CLOSES ON, stated so nothing downstream repeats the overclaim:

  CLOSED   A suite can no longer NAME the seam types. Every route the old API invited is shut: no
           shape arguments on bindSuite / atTest / defineEvidenceCapture, no shape-parameterized
           type exported to annotate a body with, no EvidenceCapture constructor to reach, no
           function declaration to merge a fresh overload onto, no interface on the seam path to
           merge a member into.

  OPEN     A deliberate structural reconstruction of the widened type out of the derived ones, and
           the pre-existing escapes: `any`, `as`, `@ts-ignore`, `@ts-nocheck`, mutating an adapter
           after it is built, and pointing AT_REPO_ROOT at another tree.

The threat model is a suite DRIFTING from its harness with nobody able to notice — an honest mistake
that type-checks green. The reconstruction above is not that: it takes `Omit`, an intersection and a
deliberate annotation, which is as considered an act as writing a cast.

The known-open case is recorded in `tests/at/typeprobes/sut-seam.probe.ts` as a comment block rather
than as live code, because that program must NOT compile and this attack does — adding it would make
the program's exit status meaningless.

This is the item's own lesson applied to itself, twice. The first version would have shipped claiming
a closure it did not have; the second version shipped a NARROWER version of the same overclaim, and
only running the compiler showed either one.
