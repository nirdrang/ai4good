### Non-Obvious Things

- **Same core, two bindings is the point.** Loop green = product decisions right; integration green additionally = schema/definers/privileges/SMTP behave. `_fixture.ts:9-14` and `_live.ts:5-18` state this explicitly.
- **World-scoped reads, not DB reset per world.** One integration run shares one DB/catcher across ~22 worlds. Every live read filters by `scopedActors() = uuidArray(knownActorIds of all opened worlds)` (`257`): deliveries by `recipient_id = any(...)`, events via `event_id in (select ... where recipient...)`, ops via same, pending same ordered by `created_at,id` (`324-432`). Addresses namespaced per world; catcher read per world addresses; transitions keyed by per-world `scopeId`. Crashed emit leaves no delivery ⇒ no event visible, which is the atomicity answer.
- **Fault point sits inside `append` between transition and event write by name and by order.** Loop restores prior transition value (not delete) to preserve earlier firings; live relies on DB transaction rollback + undo-proof sequence witness.
- **`drainDeliveries({passes:1})` exists to observe the unconfirmed state.** Run-to-quiescence would reject→retry→accept (or ack-lost→replay) inside one call, hiding the `pending/retrying`-not-`sent` clause (`_contract.ts:164-171`, `c-...:167-171,230-236`).
- **Event `attempts` counts worker passes, not provider sends.** In-app-only passes increment it with zero provider sends; suite checks both counters (`_contract.ts:106-114`).
- **`deliveredByProcess` stamps first sender only** (`_fixture.ts:292-303`); re-stamping would attribute to last drain.
- **Live `sentinels.scan` always refuses** (`CapabilityPending(['sentinels.scan'])`); bodies read delivery bodies via `sut.deliveries()` instead. `static` provider scan is `refusing()` at all tiers.
- **Above loop, `h.vendors` and `h.clock` control seams are absent from the type**, not throwing stubs — misuse is a compile error (`TierHarness`). Live provider faults live at `notifications.provider_send`, not the sim.
- **SMTP has no idempotency key**; live dedup is catcher-query-before-send in `withIdempotentReplay`, not a stored receipt (lost-ack path has no receipt to store).
- **`--expect` treats improvement as failure** and matches reds by rebuilt exact shape, not substring; redacted details fail closed.
- **Per-tier map must cover every tier or supply `default`;** uncovered tier reports `missing`, which no red declaration can describe — so hole is refused at registration.
- **Type aliases, not interfaces, on the whole seam path** (`_contract.ts:43-77`, `contracts.ts` alias rule) to defeat `declare module` augmentation silently reading `undefined`.
