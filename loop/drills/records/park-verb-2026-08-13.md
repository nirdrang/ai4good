# PARK as a verb — drill record, 2026-08-13

`PARK` is now one word with one meaning in four contracts: conductor, orchestrator, its opus
twin, and executor. This record holds the measurements behind that text.

## 1. The transport, measured live (scenario 4b)

A background parent (haiku) spawned ONE synchronous child (haiku). The child looped on a
ten-second tool call and was told to stop at once if an instruction containing `PARK` arrived.
The coordinator sent `PARK` to the blocked parent first, then to the child.

| question | answer |
|---|---|
| is a descendant the coordinator did not spawn addressable? | **yes** — it registered in the coordinator's own task list 7 s after its spawn, with its own id, and `SendMessage` to that id was accepted |
| when is a message delivered? | the tool itself answers: *"Message queued for delivery at its next tool round."* |
| does the working leaf stop? | **yes** — `PARKED AT TICK 2` of a planned 12, about 34 s in, its next tool round after the send |
| does the blocked parent ever read its park? | **yes, on the child's return** — the parent reported the message appeared *"AFTER the child returned"*, attached to that child's tool result |

Cost 31,286 subagent tokens, 52 seconds, two haiku agents.

So the park propagates **upward by the child ending**. The coordinator sends leaf first; each
blocked role collects its own queued park the moment its child returns. Nothing polls, nothing is
written to disk, and no role waits for the middle to start listening.

## 2. The guard, and proof it bites

`run-drills.ps1` gained a `park-verb` assertion: every parkable role must carry a `## PARK`
section and must report `PARKED at` a commit. Transport is not obedience — the probe child
stopped because its prompt defined the word, and a contract that loses the section turns the park
back into a phrasing that happens to work.

| state of the contracts | guard result |
|---|---|
| all four carrying the section | `missing = []` — assertion green |
| one role's heading renamed | `missing = [executor.md]` — assertion red |

The second row was produced twice: once deliberately, and once by accident when a `git checkout`
during the test discarded the uncommitted section. The guard reported it both times.

## 3. The standing suite

`run-drills.ps1` — **75 of 75 assertions green**, `All control hand-offs held.`, exit 0, at

## 4. One limit found on the way

The stamp's window line is **one turn behind**. The prompt hook runs before the status line
renders, so it prints the previous render's reading. On this morning's first prompt after an
overnight gap it read `UNKNOWN - last reading is 282.3 min old`; a tool call moments later read
0 minutes old. The rule is now in `SKILL.md`: never treat the first reading after a gap as
today's number.
