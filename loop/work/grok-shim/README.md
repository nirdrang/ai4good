This directory is a PATH-front wrapper for the grok CLI. It exists because the Claude cloud VM kernel boots without Landlock and grok 1.0.13 refuses its read-only and workspace profiles there. The wrapper rewrites those sandbox profiles, and the permission-mode and bash auto-allow settings, only when a live probe (`grep -qs landlock /sys/kernel/security/lsm`) says the kernel lacks Landlock; it prints one line to stderr for each rewrite. The runner is pointed at it with a PATH prefix.
