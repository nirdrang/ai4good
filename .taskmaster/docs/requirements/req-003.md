#### REQ-003: Project Need Creation (free-text intake)

An NGO admin starts a "Project Need" with a free-text problem description, which begins Discovery.

- Intake captures a title, problem description, and urgency — no cause field exists at intake. Cause labels are machine-generated by Discovery, not entered here (REQ-004); a draft shown before Discovery runs legitimately carries none. The NGO may remove a wrongly generated label from its project; it may never type or invent one — correction is deletion-only, invention stays machine-owned.
- Intake takes no file uploads. Reference files are added during Discovery, when the agent asks for them, or from the project page before completion (REQ-032).
- Drafts persist automatically without an explicit save. An NGO keeps one intake draft at a time and can discard it after a confirmation; on submission Discovery begins and the raw intake is retained for audit.
- Before submission the admin sees the exact public card and confirms it holds no personal details. An email address, a phone number, or a street address in the title or description blocks submission until it is removed; text that looks like a person's name gives a warning and does not block (screen design 2026-11-27).
- **On submission the intake is public** as the project's intake card (REQ-005.5, REQ-011): title, problem description, urgency, NGO name, state "Intake", and posted date. The form says plainly, before submission, that the description will be public and must not contain names, health details, or other personal details of beneficiaries.

Dependencies: REQ-001, REQ-002.
